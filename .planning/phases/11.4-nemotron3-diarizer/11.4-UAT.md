## Findings

### F-1 — Nemotron 3 never loaded in the app (fixed, `478e5e2`)

- First live run: every system-audio row was "Other". Tests were green.
- Cause: `MeetingRecorder` called `Nemotron3Models.load(config:directory:)` with the repo root. That API expects
  the `.mlmodelc` and `learnable_sil_emb.bin` in one folder; the Hub cache keeps the bundle under
  `monolithic/v2/` and the `.bin` at the root. Load threw, and the recorder silently fell back to
  source-based attribution — the error was not logged.
- Fix: load with `Nemotron3Models.loadFromHuggingFace(config:)`, which reads a complete cache without network;
  the failure reason is now logged under `LOG_SENSITIVE_DATA=1`.
- This was risk "existence check without loading" in `11.4-RESEARCH.md` §3. Unit tests cannot catch it — they
  never load the real model.

### F-2 — System audio lost after ~40 s (fixed before commit, found in review)

- The first `SpeakerBufferManager` trimmed its audio buffer with an offset that was always zero, so after the
  first trim slices were misaligned and the buffer was drained on every poll. A 90 s two-speaker test emitted
  40 s. Fixed by keeping `sessionStartTime` immutable and tracking `audioBaseSeconds`; regression test added.
- In the same review: buffer consumer was cancelled before `manager.stop()` (tail lost on stop), and system
  batches went through one `Task` each (no ordering guarantee). Both fixed — single ordered `AsyncStream`,
  stop drains capture → system stream → diarizer tail → buffer consumer.

### F-3 — Toolchain after Xcode 27 update (environment)

- Xcode updated to 27.0 (27A266a) during the phase: license had to be re-accepted and the Metal Toolchain
  downloaded (`xcodebuild -downloadComponent MetalToolchain`) — without it MLX does not compile.
- `xcodebuild` still warns about CoreDevice / CoreSimulator being out of date; harmless for build and tests
  (`xcodebuild -runFirstLaunch` clears it).

### F-4 — Flaky `DiarizationPresetSettingsTests`

- Both tests shared one `UserDefaults` suite name; under `--parallel` they cleared each other's domain.
  Suite name is now unique per test instance.
