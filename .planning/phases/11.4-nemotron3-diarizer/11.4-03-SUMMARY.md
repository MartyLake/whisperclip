# Plan 03 — Live Pipeline Integration

- `SpeakerBufferManager` now consumes scripted or Nemotron streaming chunks, aligns capture gaps
  with zero padding, builds the timeline, emits closed turns, enforces the 30 s cap and 0.5 s
  minimum, flushes the provider tail on stop, and releases old audio as it advances.

  failed model load falls back to source attribution and does not block recording. Model load

  buffer-splitting tests, and the old mock. Speaker model/display-name tests remain because they
  still cover the app's speaker-color contract.

  empty. `./local_build.sh Debug` could not run its Xcode scheme because this checkout has no
  `.xcodeproj` or workspace; SwiftPM `swift build` succeeded.
