# Plan 01 — Diarization Core

- `SpeakerTimeline` stores one byte per 10 ms frame: zero is silence and values 1–8 encode
  slot indices. This is about 360 KB per hour, versus about 11.5 MB for eight `Float32`
  probabilities per frame.
- Activity threshold is 0.5, matching FluidAudio's `Nemotron3Diarizer.segments` default.
  Same-slot gaps up to 0.2 s are joined; turns under 0.2 s are dropped, also matching the
  library's default minimum duration.
- `StreamingDiarizationProvider` exposes app-owned frame chunks, append/process/finish/reset,
  and latency. `Nemotron3DiarizationProvider` wraps the non-thread-safe model; its documented
  ownership invariant is one `SpeakerBufferManager` actor.
- Presets `fast`, `fast32`, and `fast128` map to FluidAudio configs; the default is `fast32`.
- Validation: `SpeakerTimelineTests` passed 6/6. Mock provider has no network or model access.
