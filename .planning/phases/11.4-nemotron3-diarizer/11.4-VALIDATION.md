# Phase 11.4 — Validation Strategy

> New logic with a clean seam: the timeline and the buffer cutting are pure and driven by scripted
> probabilities, so they are tested first. Attribution quality on real audio cannot be unit-tested
> (no model downloads in tests) and is covered only by the manual pass.

| Property | Value |
|----------|-------|
| **Framework** | XCTest |
| **Quick run** | `swift test --filter SpeakerTimelineTests` / `--filter SpeakerBufferManagerTests` |
| **Full suite** | `swift test --parallel --verbose` |
| **App build** | `./local_build.sh Debug` |
| **CI** | Out of scope |

## Known gaps

- No automated test runs the real model. A wrong threshold or a time-alignment bug that scripted
  probabilities do not expose is caught only in the manual pass (steps 3-6).
- Per-chunk inference cost is machine-dependent and measured only by hand.
- Download and 401/403 handling are not covered by tests (no network in tests).
