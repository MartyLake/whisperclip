Write tests first, then the code.

Types (all times in capture seconds):
- `ReconcilerTimelineView` (protocol, `Sendable`): `coveredThrough: TimeInterval` and
  `turns(from:to:) -> [SpeakerTurn]`. Tests use an in-memory fake; Plan 03 gives `SpeakerBufferManager` a
  snapshot type conforming to it.
- `ReconcilerRow`: `id: UUID`, `start`, `end`, `text`, `words: [ReconcilerWord]?` (word text + absolute start/end).
- `ReconcilerResolution`: `.label(id: UUID, speaker: Speaker)` or
  `.split(id: UUID, parts: [ReconcilerPart])`, where a part has `speaker`, `text`, `start`, `end`.

Pure function `resolve(row:timeline:)` implementing D-08:
- ignore speakers whose total time inside the row is < 0.6 s;
- one speaker → `.label`;
- several + words → each word takes the turn with most overlap over the word's span (no overlap → nearest
  turn); merge consecutive words of one speaker into one part; part text = words joined with single spaces;
  part start/end = first word start / last word end, except the first part starts at row start and the last
  ends at row end; if all words land on one speaker → `.label`;
- several, no words → `.label` with the speaker of most frames;
- no speech at all → nearest turn within 1.0 s of the row, else `.label(.other)`.
Speaker values come from `SpeakerTurn.label` → `Speaker(displayName:)`.

Test cases at minimum: single speaker; 0.4 s minority ignored; two-speaker split by words (check text
concatenation equals the original word sequence and times are contiguous); two speakers without words →
majority; silence near a turn → that turn; silence far from turns → `.other`; word straddling a boundary.

  <action>
`actor SpeakerReconciler`:
- `init(deadlineSeconds: TimeInterval, clock: @Sendable () -> TimeInterval)` — the clock is injected so tests
  control time; production passes the system-batch clock (Plan 04).
- `submit(_ row: ReconcilerRow)` queues a row.
- `poll(timeline:) -> [ReconcilerResolution]` resolves every queued row whose end + 0.2 s ≤ `coveredThrough`;
  rows past `end + deadlineSeconds` (by the injected clock) and still uncovered resolve to `.label(.other)` and are
  logged (no text in the log). Resolved rows leave the queue; output order = row start order.
- `flush(timeline:) -> [ReconcilerResolution]` resolves all remaining rows with whatever coverage exists (final).
- Deadline formula used by Plan 04: `max(10, 2 × preset latency + 2)` seconds — expose it as a static helper.
Tests: row waits until covered; deadline → `.other`; flush resolves everything; order is stable.
