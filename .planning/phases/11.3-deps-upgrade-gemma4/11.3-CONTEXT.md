# Phase 11.3: Dependency Upgrade (FluidAudio, MLX) + Gemma 4 E4B - Context

**Gathered:** 2026-10-13
**Status:** Ready for execution

<domain>
## Phase Boundary

Work resumed after a six-month pause (last commit 2026-04-20). The branch no longer builds on the
current toolchain (Swift 6.3.3 / Xcode 26.6): FluidAudio 0.10.0 fails to compile in its own sources.
This phase restores a locally building, test-passing app on current dependencies and adds
Gemma 4 E4B as a selectable local LLM.

It is a migration phase: no new product behaviour except the new LLM entry. Nemotron 3 diarization,
the Hugging Face token UI and removal of the old `DiarizerManager` path belong to Phase 11.4.

</domain>

<decisions>
## Implementation Decisions

- **D-01: Local build only.** CI (`.github/workflows/macos-build.yaml`) is out of scope and may stay red.
- **D-02: FluidAudio goes first.** 0.10.0 → 0.17.x is the first step because nothing compiles without it.
- **D-03: `mlx-swift-examples` is dropped.** `MLXLLM` / `MLXLMCommon` come from `mlx-swift-lm` 3.32.x with `mlx-swift` 0.32.x. `Package.swift` moves to swift-tools 6.2; the app target stays in Swift 5 language mode with `-strict-concurrency=complete`.
- **D-04: Other dependencies move only if resolution forces it.** WhisperKit (0.12.0, latest 1.1.1) is upgraded only if it cannot coexist with the tokenizer/Hub packages `mlx-swift-lm` 3.x needs. If it must move, the WhisperKit streaming adapter from Phase 11.2 is re-verified.
- **D-05: `DiarizerManager` keeps compiling in this phase.** It is retired in 11.4; here it is only adapted to the new FluidAudio API with minimal edits. No behaviour work on it.
- **D-06: Gemma 4 E4B is added, not made default.** `CurrentLLMModelName` stays `Qwen3_4B_4bit`; switching the default is a separate decision after UAT.
- **D-07: `project.yml` mirrors `Package.swift`.** Every dependency change is applied to both files in the same commit.
- **D-08: No working baseline exists**, so regressions cannot be found by comparison. Parakeet streaming, file transcription, WhisperKit transcription and LLM enrichment are verified manually at the end of the phase.

</decisions>
